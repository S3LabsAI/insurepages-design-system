# SectionHeader

The centred block that opens every home-page section: a lavender eyebrow label, an Unbounded title and an optional subtitle.

Static rendition of `.section-head`, `.section-eyebrow`, `.section-title` and `.section-sub` from `site/src/styles/global.css`. The consumer supplies the eyebrow (2–3 words, rendered uppercase), the title (one short sentence, max-width 900px) and an optional one-line subtitle in `body-secondary`. Leave 64px (`space-head-bottom`) before the section content.
